- 캔버스 64x64 도트를 10배 확대한 640x640 PNG입니다.
- 캐릭터 스프라이트(콘도/레이/애슐리)는 임시 디자인입니다. `make_art.py`의 `KONDO_ROWS`, `REI_ROWS`, `ASH_ROWS`와 팔레트를 실제 디자인으로 바꾸면 전체 그림에 반영됩니다.
- 재생성: `python3 make_art.py` (Python 표준 라이브러리만 사용)
