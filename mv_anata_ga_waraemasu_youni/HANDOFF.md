## 2. 꼭 알아야 할 결정 사항

### 곡 정보
- 음원: `あなたが笑えますように V3_FINAL.mp3` (사용자 보유. 저장소에는 없음 → 로컬 경로를 사용자에게 확인)
- 4:09.3, **BPM 99**, 4/4, G장조. **앞부분 무음 4.86초**
- 마디 공식: `마디 n의 시작(초) = 4.86 + (n−1) × 2.42424`
- 섹션 시작(사용자 확인 완료): Pre-Chorus **0:58.2**, Chorus **1:12.7**, 「あなたが笑うたび」 **3:28.5**
- 섹션 안의 줄 단위 시간은 마디 그리드 기준 **추정** → 타임라인 작업 때 파형 보고 미세 조정 필요

### 연출 원칙
- **미러 구도**: 1절(「あなた」) ↔ 2절(과거의 애슐리)이 같은 구도. IL02↔IL08, IL03↔IL09, IL05↔IL10. Outro는 1절 장소의 밝은 버전(OUT01 = IL05 방의 아침, OUT02 = IL03 횡단보도의 낮)
- 「あなた」: 얼굴을 절대 보이지 않음. 회색 후드 + 어두운 코트/긴 바지 + 짧은 검은 머리. 성별 중립
- 애슐리: 금발, **파란 나비 머리핀**, 학교에선 **로퍼**(스니커 X). **산속 저택**에 살고 방은 원목 기반 (도시·현대적 인테리어 NG)
- 연인처럼 보이는 구도는 NG (팬 배려) → IL16은 시청자 시점(POV)
- 카메오(콘도상·레이) 없음
- 나비·빛 파티클·파란 실은 일러스트에 넣지 않고 리졸브에서 소재 합성 (IL05, IL07, IL15 등 일부 제외)

### 사용하는 일러스트 (총 28장 이내)
`STORYBOARD.md` 4장 「일러스트 목록」 참고. ID 목록:

- Intro: `IL01`, `IN01`, `IN02`
- Verse 1: `IL02`, `IL03`, `IL04b`, `IL04`, `IL05`
- Pre/Chorus 1: `IL06b`, `IL06a`, `IL07`
- Verse 2: `IL08`, `IL09`, `IL09b`, `IL10`, `IL10c`, (`IL10d`), (`IL10e`)
- Pre/Chorus 2: (`IL11`), `IL12`
- Bridge: (`IL13`), `IL14`, `IL14b` / Bridge B는 검은 화면 + 문자만
- Final: `IL15`, `IL16`
- Outro: `IL17`, `OUT01`, `OUT02`, IL01 낮 버전(색보정으로 처리)

( ) = 선택. 실제로 생성한 장수는 사용자에게 확인.

## 3. 부분 수정 (ComfyUI + Qwen-Image-Edit)

### 할 일
1. 사용자에게 **수정할 그림 목록과 각 수정 내용**을 받는다 (아직 미정)
2. Qwen-Image-Edit 워크플로로 해당 부분만 수정
3. 수정 전/후를 나란히 보여 주고 확인받기

### 수정 시 자주 체크할 포인트 (지금까지 나온 문제들)
| 체크 | 해당 그림 |
|---|---|
| 애슐리 발에 스니커 → 로퍼로 | IL06·IL13·IL14·IL16·IL17 등 애슐리 발이 보이는 컷 |
| 「あなた」가 맨다리 → 긴 바지 | IL13·IL14·IL06a |
| 「あなた」 얼굴이 보임 → 숨기기 | 「あなた」 등장 컷 전부 |
| 나비 머리핀 누락 | 애슐리 머리가 보이는 컷 전부 |
| IL10 계열에 도시·현대적 소품 | IL10·IL10c·IL10d·IL10e |
| 문자 넣을 여백이 막힘 | 프롬프트의 `Leave empty space ...` 위치 참고 |
| 미러 쌍의 구도 차이가 너무 큼 | IL02↔IL08, IL03↔IL09, IL05↔IL10, IL05↔OUT01, IL03↔OUT02 |

### 수정 지시 작성 요령 (Qwen-Image-Edit)
- 한 번에 하나만 바꾸기 (「신발을 갈색 로퍼로 바꿔 줘」 + 「나머지는 그대로」)
- 바꿀 대상을 위치로 특정 (「오른쪽 소녀의 발」처럼)
- 영어 지시가 더 안정적일 때가 많음. 예: `Change the girl's sneakers to brown loafers with black socks. Keep everything else unchanged.`
- 결과가 전체 그림을 바꿔 버리면 마스크(인페인트) 방식으로 전환

## 4. 업스케일

- 목표: **3840×2160 (4K)** 이상. 리졸브에서 최대 120~130%까지 줌인하므로 1080p 최종 출력이라도 4K 소스가 필요
- 특히 줌이 큰 그림: `IL06a`, `IL06b`, `IL07`, `IL15`, `IN02`(타이틀 배경)
- ComfyUI 표준 노드 `Load Upscale Model` → `Upscale Image (using Model)`로 애니메이션용 업스케일 모델 사용 (모델 선택은 사용자 환경에 맞춤)
- 업스케일 후 16:9 비율이 유지되는지 확인 (생성 해상도 1344×768은 정확히 16:9가 아님 → 업스케일 후 **3840×2160으로 크롭**. 문자 여백 쪽은 자르지 않도록)

### 파일 규칙
```
mv_anata_ga_waraemasu_youni/
  images/
    original/   ← PixAI 원본  (IL01.png …)
    edited/     ← Qwen 수정본 (같은 파일명)
    final/      ← 업스케일·크롭 완료본 (타임라인은 여기만 참조)
```
- 파일명은 ID 그대로: `IL01.png`, `IL04b.png`, `IN02.png`, `OUT01.png` …
- 이미지(특히 4K)는 용량이 크므로 **git에는 커밋하지 않는 것을 권장** (`.gitignore`에 `images/` 추가 여부는 사용자에게 확인)

## 5. 리졸브 타임라인 (4번 단계)

### 만들 것
1. **FCPXML 타임라인**: 컷 단위로 `images/final/` 이미지 배치 + 음원 트랙 + 섹션 마커
   - 컷 시간·사용 이미지·카메라 움직임은 `STORYBOARD.md` 3장 표 그대로
   - 줌·팬은 키프레임(Transform) 또는 리졸브에서 수동. FCPXML에 넣을 수 있는 범위는 리졸브 버전 확인 후 결정
   - 섹션 마커: Intro / Verse 1 / Pre 1 / Chorus 1 / Verse 2 / Pre 2 / Chorus 2 / Bridge A / Bridge B / Final / Outro
2. **SRT 가사 자막**: 줄 단위 타이밍. 리졸브에서 불러와 폰트·연출은 수동 (타이포 규칙은 `STORYBOARD.md` 2장)
3. (선택) **ffmpeg 미리보기 mp4**: 타이밍 확인용
